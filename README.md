# 🍎 Fruit Collecting Game

Catch the fruits on the farm but beware of bombs

Fruit Collecting Game is a Unity project where the player controls a basket to collect falling fruits on a farm. Every fruit you catch earns points but catching a bomb ends the game immediately. The challenge is to collect as much as possible before time runs out.

## 🎮 Game Concept

Fruits fall from the top of the screen
The player moves a basket at the bottom to catch them
✅ Catch fruit → earn points
💣 Catch bomb → instant game over
❌ Miss fruit → lose a life (optional)
The game ends when the timer runs out or when a bomb is caught

## 🎮 Features

🍎 Fruit Spawner: Randomly drops apples, bananas, oranges and more
💣 Bomb Spawner: Drops bombs that end the game if caught
🧺 Basket Movement: Player moves left and right to collect fruits
📈 Score System: Gain points for every fruit caught
❤️ Lives System: Lives decrease if you miss fruits
⏱️ Timer: Collect as much as possible before time runs out
🌾 Farm Background: Simple farm themed backdrop for the game world
🎨 UI Screens: Title, gameplay HUD with score, lives and timer, win and lose screens

## 📂 How to Play

Launch the game from the Title Screen

Use the arrow keys (← →) or A and D keys to move the basket

Catch fruits to gain points

Avoid bombs because catching one ends the game instantly

Survive until the timer ends and try to beat your high score

## 🎨 Design

Background: Simple farm scene with sky and fields
Fruit Sprites: Apples, bananas, oranges and more
Bomb Sprite: Clearly distinct from fruits to avoid confusion

UI Elements: Score counter, timer and lives tracker
